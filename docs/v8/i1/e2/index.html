Abstract

Semantic alignment between heterogeneous terminologies is a central prerequisite for interoperability in Knowledge Graph ecosystems. While SKOS provides well-established mapping properties for expressing semantic correspondences, these relations are inherently qualitative and lack an explicit, machine-actionable notion of mapping strength. This limits their use in quantitative analysis, ranking, and automated reasoning within research data infrastructures. This paper introduces Gradual Semantic Alignment for SKOS (GSAS), a methodological framework that augments SKOS mappings with a normalised degree of connection in the interval [0,1]. GSAS comprises four complementary models, ranging from a minimal SKOS-based baseline to graded and empirically grounded approaches derived from linguistic probability perceptions. All models are formally defined, interoperable, and remain fully compatible with existing SKOS semantics. The methodology is operationalised in an open-source software reference implementation that produces reproducible RDF outputs and a unified SKOSplus ontology. An application example demonstrates how GSAS enables transparent comparison of alignment strategies and supports reusable, quantitative semantic alignment across domains.

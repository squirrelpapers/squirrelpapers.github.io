FAIRyland: A playful dataset for teaching Linked Open Data in archaeology

Florian Thiery, Brigit Danthine, Nadine Alpino

Zitiervorschlag

Thiery, F., Danthine, B., & Alpino, N. (2026). FAIRyland: A playful dataset for teaching Linked Open Data in archaeology. Squirrel Papers, 8(2), §5. https://doi.org/10.5281/zenodo.18901448

Zusammenfassung

FAIRyland is an open educational resource (OER) combining fictional archaeology with real research software engineering methods. The dataset simulates a Minion Period archaeological site in northern Sweden, featuring craters, streets, petrified kangaroo droppings (Kötbullar), and other playful features. It demonstrates the complete workflow from QGIS vector data to RDF/Linked Open Data using the SPARQLing Unicorn plugin, followed by SPARQL querying and Python-based visualisation. The repository includes geospatial data (GeoJSON, GeoPackage), RDF triples in Turtle format with CIDOC-CRM and GeoSPARQL vocabularies, seven interactive SPARQL queries, Python scripts for data analysis and visualisation (rdflib, pandas, matplotlib, GeoPandas), and Jupyter Notebooks for hands-on learning. FAIRyland serves as a practical sandbox for students and researchers to learn semantic web technologies, geospatial analysis, and FAIR data principles through an accessible, playful framework.

Über die Squirrel Papers

Die Squirrel Papers des Research Squirrel Engineers Network sind ein kostenfreies Open-Access-Journal mit Publikationen auf Zenodo und dem Open Science Framework (OSF). Sie sammeln Forschungsarbeiten, Working Papers, Blogbeiträge, Poster, Folien, Forschungsdaten und Forschungssoftware aus den Bereichen Linked Open Data (LOD), Research Software Engineering (RSE), Kulturerbe und Geowissenschaften.

Die Squirrel Papers sind ein offiziell vom Nationalen ISSN-Zentrum für Deutschland anerkanntes Journal mit der ISSN 2750-560X.
